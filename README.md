# Durvankur Kansare — Portfolio (Assignment 9)

A responsive personal portfolio made with HTML, CSS, JavaScript, and Tailwind CSS.

## Included features
- Home section with introduction and profile photo
- About, Education, Skills, Projects, Certifications, and Contact sections
- Times New Roman across all text
- Tailwind CSS utility classes (loaded via CDN)
- CSS reveal animations and hover transitions
- Responsive sticky navigation with mobile hamburger menu
- Active navigation highlight while scrolling
- Project detail popups
- Back-to-top button
- Downloadable resume PDF
- Responsive layout for mobile, tablet, and desktop

## Run locally
This is a static website. You can open `index.html` in a browser, but using VS Code Live Server is recommended.

1. Extract the ZIP.
2. Open the `durvankur-portfolio` folder in VS Code.
3. If you have Live Server installed, right-click `index.html` and choose **Open with Live Server**.
4. Otherwise, open `index.html` directly in your browser. Tailwind CDN needs an internet connection.

## Deploy to Netlify
1. Extract the ZIP.
2. Open Netlify and sign in.
3. From the Netlify dashboard, choose the option to add/deploy a site manually (often labelled **Netlify Drop** or **Deploy manually**).
4. Drag the extracted `durvankur-portfolio` folder into the upload area. If the interface requires a ZIP, upload the ZIP file instead.
5. Wait for the deploy to finish and open the generated site URL.
6. Test the site on your phone and check that the photo, navigation, project popups, and resume download work.

No build command or publish directory is required for this static project. The `index.html` file is at the project root.
